# Mummy’s & Me — four separate HTML pages

Files:
- `index.html` — Home
- `blog.html` — Blog
- `products.html` — Products
- `help.html` — Help, general contact and advertising enquiry
- `styles.css` — shared responsive CSS used by all four pages
- `script.js` — shared JavaScript used by all four pages

Each HTML file contains its own SEO title and meta description and links to the shared CSS and JavaScript. This is a standard maintainable way to keep the same design and interactions across separate pages.

## GitHub Pages
Upload all six files to the root of your GitHub repository. Then go to Settings → Pages → Deploy from a branch, select `main` and `/ (root)`, and save. `index.html` is the homepage.

## Email forms
Forms are configured for FormSubmit at `2515812@live.stmarys.ac.uk`. Publish first, submit a test form, and follow the activation email sent to that inbox. FormSubmit is a third-party processor; review its terms and privacy information. Add a complete privacy notice and appropriate marketing consent/unsubscribe process before collecting real subscribers.

The daily inspiration message is stored per browser/device and changes on a later calendar day. GitHub Pages is static hosting; FormSubmit handles form email delivery externally.
